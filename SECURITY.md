# Security policy / セキュリティ方針

## English

Buildoffice 0.2.0 is a preview release. If you find a security problem (a vulnerability), please report
it privately with GitHub's **Private vulnerability reporting**: open this repository's **Security** tab
and choose **Report a vulnerability**.

Please do **not** write about a vulnerability in a public issue, pull request or discussion, and do not
publish the details before it is fixed.

In the report, please tell us the version, what you did, what happened and what you expected. Do not send
real private data (use a test vault). This is a preview, so no response time is promised.

## 日本語

Buildoffice 0.2.0 はプレビュー版です。セキュリティの問題（脆弱性）を見つけたときは、GitHub の
**Private vulnerability reporting** で、非公開で知らせてください。このリポジトリの **Security** タブを開き、
**Report a vulnerability** を選びます。

脆弱性のことは、公開の issue・プルリクエスト・ディスカッションに**書かないで**ください。直るまでは、
詳しい内容を公開しないでください。

報告には、版・やったこと・起きたこと・期待したことを書いてください。本物の個人のデータは送らないでください
（テスト用の保管庫を使ってください）。プレビュー版なので、返事までの時間は約束できません。
